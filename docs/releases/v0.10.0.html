Noor · release v0.10.0 · 2026-10-01

Lessons that finish, and a tutor that stays signed in

Tamer tested the product on 29–30 September and fixed what he found. Samuel reviewed the eight changes and accepted them all on 1 October.

What changes for a student

Changed The map is back in the header, as "Your Progress"

Before
The header said "Study" and "Where you stand". The map was only reachable from buttons that said "See it on the graph".
Now
The header says "Study" and "Your Progress". Every button to the map says "See your progress". The "Where you stand" page still exists but is off the header.

Changed Opening the site goes straight to Study

Before
A signed-in student who opened the home page saw the July investor preview: corpus counts, "AI turns logged", demo cards.
Now
They land on Study. Signed-out visitors still see the welcome page.

Fixed A lesson can be finished

Reported
A tester finished lesson 1-1 with a 95% report, and the lesson never moved on.
What was wrong
Finishing needed every objective at 75%. "Quick review" only asks about the first three objectives, and 1-1 has four, so it could never pass.
Now
A lesson is finished when every objective has been tried at least once and the lesson's average reaches "Getting there". The "whole course complete" banner still needs 75% everywhere. A wrong first answer can now finish a lesson too.
Trade-off
One weak objective no longer holds a lesson back. The lessons that build on it still check it.

Fixed No more "AI backend unavailable" after 15 minutes

Reported
After about 15 minutes in one lesson, the next message failed with "AI backend unavailable", and retrying did not help.
What was wrong
The sign-in lasts 15 minutes and nothing renewed it while the page was open. Answers given in widgets were probably lost without any sign.
Now
The page renews the sign-in while the student is active, and retries once if a request is refused. If the student really is signed out, the chat says so instead of blaming the AI.

Fixed The explanation above a widget stays on screen

Before
A tall widget pushed the tutor's explanation, and sometimes the question itself, off the top of the screen.
Now
The message is shown from its top. The student reads the explanation, then scrolls down to the widget.

Changed How the tutor talks

"LO"
The tutor used to say "this LO" to students. It now says "learning objective" or names the idea.
Your Progress chat
It was still the investor-demo version, talking about the student to "an observer" and offering quizzes. It now talks to the student, explains and plans, sends them to Study to practise, and describes progress in words, never as a number.
Data
These are prompt changes, so tutoring data before and after this release should not be compared directly.

Still open

Open The chat can jump after answering a widget

If a widget grows after the student answers it (for example, to show feedback), the chat can scroll back to the top of that message. Found in review; to be fixed next.

Open Not yet tried on an iPad

All of this was checked on a desktop browser and by automated tests. None of it has been run on iPad Safari yet.
