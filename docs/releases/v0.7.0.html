The teaching switch

New Console → Teaching

What it does
Socratic probing (after a wrong answer, Noor asks a guiding question instead of showing the solution) has three positions: Off (the default), Test accounts only, and Everyone, which stays locked until issue #53 is fixed.
Who can move it
Operators holding the new teaching-controls role. Today that is all three founders, and it can be removed from anyone later without touching their other rights.
When it takes effect
Off reaches a student's very next message. On only affects lessons that start afterwards. Once a lesson stops probing, it never starts again.
Where it applies
Maths lessons in "walk me through it" mode only. Social Studies, Arabic and review mode never probe.

New Test accounts

What it does
On a student's console page, an operator marks the account as a test account. With the switch on "Test accounts only", only those accounts get probing.
Rule
Only accounts the team owns, never a real student. Marking needs both student-data and teaching-controls. Who marked it and when is recorded, and a removed mark is stamped, never deleted.

New Which version, which mode

What it records
Every lesson records the version that served it and whether probing was on. The console header shows the deployed version and the switch position. Each student's lesson list shows both.
