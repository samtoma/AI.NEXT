## How to use this doc

- **Kind + target skill** tells you whether a row is `/feedback` (an
  observation) or `/requirement` (asking the spec itself to change). Filing a
  requirement-shaped item through `/feedback` will get it filed, but triage
  will just have to reclassify it — do it right the first time.
- **Related FR/SC** is only ever a *pointer* — checked against
  [`specs/001-student-mvp1-delta/traceability.md`](../../specs/001-student-mvp1-delta/traceability.md)
  just now, never invented. Where a row cites one, say so explicitly when
  filing (`/feedback` step 2 asks for exactly this).
- **Quadrant** is engineering-execution guidance (parallel safety), not a
  triage outcome. It answers "who can pick this up and when," not "should we
  build it."
