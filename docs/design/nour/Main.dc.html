Ordered pairs

Question 2

If (x − 4, 7) = (9, y + 2), find the value of x × y.

Two ordered pairs are equal when their first components are equal and their second components are equal.

(a, b) = (c, d) ⟺ a = c and b = d

You set the second components equal and got y = 5. That part is right.
