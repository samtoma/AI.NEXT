Find the set of ordered pairs (x, y) which satisfy the relation y = 2x - 1 when x = 0, x = 1 and x = 2. Tap the pairs that satisfy the relation.

What the blind checker read off the question:

{"X": [0, 1, 2], "Y": [-1, 1, 3], "pairs": [[0, -1], [1, 1], [2, 3]]}

method hint a student whose construction fires extra-pairs (“Selected pairs that are not in X×Y at all”) is shown, from step 2 of the solution:

Substitute each x into y = 2x - 1 and compute y. Only a pair whose y matches that result belongs in the set.

checker refused It is in the can_emit table for relation mode. It fires when the student taps a pair of X×Y that the rule leaves out, such as (0,1). The hint's description says 'not in X×Y at all', which is wrong: these pairs are in X×Y, they just fail the rule. The hint text itself is mathematically right and doesn't give the answer. But it says 'Only a pair whose y matches that result belongs', which nearly directs the student to the answer. The mismatch between the predicate description and the situation makes this a risky hint, so it is rejected.

How the checker built a correct answer

Mode relation with X=[0,1,2], Y=[-1,1,3]. Tap (0,-1), (1,1), (2,3). Each satisfies y=2x-1 and the set has one pair per x. Reachable, within the small-set limits (3 numbers each). Y is not given in the question, so the Y set is inferred from the rule's outputs, which is a reasonable reading.
